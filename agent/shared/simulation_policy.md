# 시장 시뮬레이션 정책

시장 시뮬레이터는 실거래 검증 환경이며 Toss 주문 경로와 분리한다. 시뮬레이션 역할이 만든 주문 객체는 다음과 같은 가상 주문일 뿐 브로커로 전송하지 않는다.

- 연속 이중경매 또는 명시된 시장 규칙
- 가격-시간 우선 호가창, 시장가/지정가, 부분 체결, 미체결 수량
- 현금·보유수량 사전 검증, 수수료·스프레드·슬리피지
- 라운드별 무작위 주문 순서와 모든 가상 상대방·체결 로그

실험 보고서는 시작 가격, 배당/금리 가정, 참가자 프롬프트 버전, 주문 규칙, 비용, 시드, 데이터 구간을 기록한다. 시뮬레이션 성과는 실거래 기대 수익으로 표현하지 않는다.
