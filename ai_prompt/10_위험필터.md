# 한눈에 보기

이 논문은 LLM에게 미래 가격을 직접 예측시키지 않는다.

먼저 통계모델이 예측시장 계약 사이에서 선행-후행 관계 후보를 찾는다. 그다음 LLM은 두 사건의 자연어 설명을 읽고, 발견된 관계에 실제 경제·정치·물리적 전달경로가 존재하는지를 평가한다.

```text
Kalshi 경제 예측시장
  ↓
YES 계약 가격 시계열
  ↓
로그 오즈 변환·정상성 처리
  ↓
양방향 Granger 검정
  ↓
통계적으로 강한 방향성 후보 Top 100
  ↓
GPT-5-nano의 의미론적 재정렬
  ↓
최종 선행→후행 쌍 Top 20
  ↓
선행 계약 가격이 움직이면
다음 날 후행 계약에 진입
  ↓
고정 기간 후 청산
  ↓
실현 PnL로 관계의 견고성 평가
```

핵심 결론은 LLM이 대형 수익 거래를 새로 많이 만드는 것이 아니라, **통계적으로는 그럴듯하지만 미래 구간에서 큰 손실을 내는 취약한 관계를 순위 밖으로 밀어낸다**는 것이다.

기본 설정에서 논문이 보고한 결과는 다음과 같다.

| 지표 | 통계 단독 | LLM 하이브리드 |
| --- | ---: | ---: |
| 승률 | 51.4% | 54.5% |
| 평균 이익 | $724 | $636 |
| 평균 손실 | -$649 | -$347 |
| 누적 PnL | $4,100 | $12,500 |

평균 이익은 오히려 작아졌지만 평균 손실의 절댓값이 46.5% 줄었다. 따라서 LLM의 주된 역할은 알파 예측기라기보다 **의미론적 리스크 필터**다.

# 이 논문이 하지 않은 것

다음과 같은 연구로 오해하면 안 된다.

- GPT-5가 가격 시계열을 직접 예측한 연구가 아니다.
- LLM이 전체 사건쌍에서 새로운 관계를 발굴한 연구가 아니다.
- LLM이 통계검정을 대체한 연구가 아니다.
- 자연어 설명만으로 거래한 연구가 아니다.
- 인과관계의 참·거짓 Ground Truth를 직접 검증한 연구가 아니다.
- Sharpe Ratio나 MDD를 보고한 연구가 아니다.
- 실제 주문장과 슬리피지를 재현한 실거래 연구가 아니다.

LLM은 Granger 검정을 통과한 후보를 **재정렬**한다. 관계 품질의 평가는 간단한 후행계약 매매전략의 아웃오브샘플 PnL로 대신한다.

# 업로드된 해설에서 수정해야 할 핵심 사항

## 1. 사용 모델

업로드된 해설:

```text
GPT-4o 및 주요 상용·오픈소스 프론티어 LLM
```

원문:

```text
주 실험: GPT-5-nano
추가 모델 확인: GPT-5-mini
```

여러 상용·오픈소스 모델을 광범위하게 비교한 실험은 아니다.

## 2. LLM 점수 체계

업로드된 해설은 1~5점의 plausibility score와 `4점 이상 통과` 규칙을 제시한다.

원문의 부록 프롬프트는 다음 구조다.

```json
{
  "has_mechanism": true,
  "strength": "high",
  "sign": "positive",
  "reason": "간단한 설명"
}
```

실제 값 범위는 다음과 같다.

```text
has_mechanism: true / false
strength: high / medium / low / none
sign: positive / negative
reason: brief explanation
```

원문에는 `4점 이상만 통과`와 같은 1~5점 하드 컷오프가 없다.

## 3. 관계 방향의 부호

업로드된 해설은 Granger 회귀계수 \(\beta_k\)의 합으로 부호를 정한다고 설명한다.

원문의 공식은 다음과 같다.

\[
s
=
\operatorname{sgn}
\left(
\operatorname{corr}(x_{L,t},x_{F,t})
\right)
\in\{-1,+1\}
\]

즉, 선행·후행 방향은 Granger 검정으로 정하지만, 같은 방향으로 움직이는지 반대 방향으로 움직이는지는 **Pearson 상관계수의 부호**로 정의한다.

## 4. 기본 거래 트리거

업로드된 해설은 5% 또는 10% 같은 임계값 예시를 중심으로 설명한다.

논문의 기본 설정은 다음과 같다.

\[
\theta=0
\]

따라서 선행계약의 상대가격 변화가 0보다 크기만 하면 거래 신호가 발생한다.

```text
기본 조건:
|r_{L,t}| > 0
```

논문의 5~10pt와 10pt 이상 결과는 기본 트리거가 아니라 **선행가격의 움직임 크기별 하위분석**이다.

# 연구 문제

## 통계적 유의성과 경제적 타당성의 차이

두 시계열 사이에서 낮은 p-value가 나왔다는 사실은 다음만 의미한다.

```text
과거 표본 안에서
X의 과거값이
Y의 미래값 예측에
추가적인 정보를 제공했다.
```

다음을 의미하지는 않는다.

```text
X가 실제로 Y를 발생시켰다.
관계가 미래에도 유지된다.
두 사건 사이에 직접적인 경제경로가 존재한다.
```

논문은 이 차이를 다음 두 계층으로 처리한다.

```text
통계 계층:
방향성 예측력이 있는 후보를 빠르게 탐색

의미 계층:
그 관계를 설명할 현실적 전달경로가 있는지 검사
```

## 다중검정과 데이터 스누핑

이론적으로 554개 시장이 한 윈도에 모두 존재한다면 비순서 사건쌍의 수는 다음과 같다.

\[
\binom{554}{2}
=
\frac{554\times553}{2}
=
153{,}181
\]

각 쌍의 양방향을 검사하면 다음과 같다.

\[
153{,}181\times2
=
306{,}362
\]

각 방향에 1~5 lag를 모두 적용하면 최대 단순 계산상 다음 수준의 검정을 수행할 수 있다.

\[
306{,}362\times5
=
1{,}531{,}810
\]

실제로는 각 윈도에서 거래 가능한 시장 수가 다르므로 정확한 검정 수는 이보다 작을 수 있다. 그래도 수많은 검정 중 가장 작은 p-value를 선택하면 우연히 유의해 보이는 관계가 대량으로 발생할 수 있다.

논문은 LLM 필터가 이런 취약한 관계를 줄일 수 있는지를 실험한다. 다만 Bonferroni나 Benjamini-Hochberg FDR 같은 공식적인 다중검정 보정을 적용했다고 명시하지 않는다.

# 예측시장 데이터

## YES 가격

예측시장 계약은 사건이 발생하면 보통 일정 금액을 지급한다.

예를 들어 다음 계약을 생각할 수 있다.

```text
"2025년 미국 GDP 성장률이 2%를 초과하는가?"
```

YES 가격이 65라면 시장이 해당 사건의 발생확률을 대략 65% 수준으로 평가하는 것으로 해석한다.

논문은 일별 YES 가격을 다음처럼 정의한다.

\[
p_{i,t}\in[0,100]
\]

- \(i\): 사건 계약
- \(t\): 날짜
- \(p_{i,t}\): 백분율 포인트로 표시한 일별 YES 가격

예측시장의 장점은 숫자 시계열과 자연어 사건설명이 직접 연결된다는 점이다.

```text
시계열:
62 → 66 → 71 → 68

자연어:
"중국의 GDP 성장률이 5%를 초과할 것인가?"
```

일반 주식가격은 기업의 모든 정보를 한 가격에 압축하지만, 예측시장 계약은 가격이 어떤 사건확률을 나타내는지가 명확하다.

# 로그 오즈 변환

YES 가격은 0과 100 사이에 제한된다.

이를 실수 전체 범위로 바꾸기 위해 다음 변환을 사용한다.

\[
\ell_{i,t}
=
\log
\left(
\frac{p_{i,t}}
{100-p_{i,t}}
\right)
\tag{1}
\]

## 변환 예시

| YES 가격 | 오즈 | 로그 오즈 |
| ---: | ---: | ---: |
| 1 | \(1/99\) | 약 -4.595 |
| 25 | \(25/75\) | 약 -1.099 |
| 50 | \(50/50\) | 0 |
| 75 | \(75/25\) | 약 1.099 |
| 99 | \(99/1\) | 약 4.595 |

50을 중심으로 대칭적이며, 0이나 100에 가까울수록 절댓값이 급격히 커진다.

## 0과 100의 문제

가격이 정확히 0이면 다음이 된다.

\[
\log(0)=-\infty
\]

가격이 정확히 100이면 분모가 0이 된다.

따라서 구현에서는 일반적으로 다음처럼 clipping해야 한다.

\[
\tilde p_{i,t}
=
\min
\left(
100-\epsilon,
\max(\epsilon,p_{i,t})
\right)
\]

\[
\ell_{i,t}
=
\log
\left(
\frac{\tilde p_{i,t}}
{100-\tilde p_{i,t}}
\right)
\]

논문은 로그 오즈 변환을 명시하지만 \(\epsilon\) 값이나 0·100 가격의 처리방법은 제시하지 않는다.

# 방향성 선행-후행의 정의

두 시계열을 다음과 같이 두자.

\[
\{x_t\}_{t=1}^{T},
\qquad
\{y_t\}_{t=1}^{T}
\]

\(x\)가 \(y\)를 선행한다는 것은 어떤 예측시계 \(h>0\)에서 다음 조건이 성립하는 것으로 정의한다.

\[
E
\left[
y_{t+h}
\mid
x_{1:t},y_{1:t}
\right]
\neq
E
\left[
y_{t+h}
\mid
y_{1:t}
\right]
\]

즉, \(y\) 자신의 과거뿐 아니라 \(x\)의 과거까지 알았을 때 \(y\)의 미래 예측이 달라진다.

이 관계는 비대칭이다.

\[
x\rightarrow y
\not\Rightarrow
y\rightarrow x
\]

# 정상성 처리

Granger 검정은 일반적으로 정상적이거나 정상성에 가까운 시계열을 전제로 한다.

논문의 각 60일 학습 윈도에서는 다음을 수행한다.

```text
로그 오즈 시계열
  ↓
ADF 단위근 검정
  ↓
비정상성 감지 시 1차 차분
  ↓
Granger 검정
```

## ADF 검정

ADF의 귀무가설은 보통 다음과 같다.

```text
H0:
시계열에 단위근이 존재한다.
즉, 비정상적이다.
```

p-value가 기준보다 작으면 귀무가설을 기각하고 정상성에 가까운 것으로 본다.

## 1차 차분

\[
\Delta x_t
=
x_t-x_{t-1}
\]

로그 오즈의 1차 차분은 사건확률의 수준이 아니라 변화량에 가까운 정보를 나타낸다.

## 재현성에 필요한 미제시 정보

논문에는 다음 값이 충분히 설명되지 않는다.

- ADF 유의수준
- 상수항·추세항 포함 여부
- ADF lag 선택 기준
- 결측치 처리
- 시장 휴장일 정렬
- 비동시 거래일 보간 방식
- 1차 차분 후에도 비정상적인 시계열의 처리
- 60일 중 최소 유효 관측치

# Granger 인과성 검정

## 비제약 모형

후행 후보 \(y_t\)를 다음처럼 예측한다.

\[
y_t
=
\alpha_0
+
\sum_{k=1}^{p}
\alpha_k y_{t-k}
+
\sum_{k=1}^{p}
\beta_k x_{t-k}
+
\varepsilon_t
\tag{2}
\]

- \(p\): lag 길이
- \(\alpha_k\): 후행계약 자신의 과거 효과
- \(\beta_k\): 선행후보의 과거 효과
- \(\varepsilon_t\): 오차항

## 제약 모형

선행후보 \(x\)를 제외하면 다음과 같다.

\[
y_t
=
\alpha_0
+
\sum_{k=1}^{p}
\alpha_k y_{t-k}
+
\varepsilon_t
\]

## 귀무가설

\[
H_0:
\beta_1
=
\beta_2
=
\cdots
=
\beta_p
=
0
\]

귀무가설이 기각되면 \(x\)의 과거가 \(y\) 예측에 추가적인 정보를 제공한다고 판단한다.

## F 통계량의 일반형

제약모형과 비제약모형의 잔차제곱합을 각각 \(RSS_R\), \(RSS_U\)라고 하자.

\[
F
=
\frac{
(RSS_R-RSS_U)/q
}{
RSS_U/(n-k_U)
}
\]

- \(q\): 제약조건 수, 일반적으로 lag 수 \(p\)
- \(n\): 유효 표본 수
- \(k_U\): 비제약모형의 파라미터 수

F 통계량이 크고 p-value가 작으면 선행후보의 과거값이 예측력을 추가한다고 본다.

# Stage 1: 통계적 후보 생성

각 비순서 사건쌍 \(\{i,j\}\)에 대해 두 방향을 모두 검사한다.

```text
i → j
j → i
```

lag는 다음 집합을 순회한다.

\[
L\in\{1,2,3,4,5\}
\]

각 쌍에서 통계적으로 더 강한 방향을 남기고 전체 방향쌍을 p-value 기반으로 정렬한다.

```text
전체 사건쌍
  ↓
양방향 검사
  ↓
lag 1~5 검사
  ↓
각 쌍의 강한 방향 선택
  ↓
전체 방향쌍 통계순위
  ↓
Top K = 100
```

## 선택 과정의 통계적 문제

다음 작업을 한꺼번에 수행하면 선택편향이 커진다.

- 두 방향 중 더 작은 p-value 선택
- 5개 lag 중 가장 강한 결과 선택
- 수많은 사건쌍 중 Top 100 선택

이것은 `최솟값을 반복 선택`하는 구조다.

예를 들어 아무 관계가 없는 경우에도 여러 p-value 중 최소값은 작아질 가능성이 높다.

따라서 엄격한 구현에는 다음이 추가되는 편이 좋다.

- FDR 보정
- lag 선택을 위한 AIC·BIC
- 방향·lag 선택과 검정표본 분리
- nested validation
- block bootstrap
- 안정성 선택
- 윈도 간 관계 생존율

# 관계의 동행 부호

선행·후행 관계가 같은 방향인지 반대 방향인지 다음과 같이 정의한다.

\[
s(L\rightarrow F)
=
\operatorname{sgn}
\left(
\operatorname{corr}
(x_{L,t},x_{F,t})
\right)
\tag{3}
\]

## 해석

\[
s=+1
\]

```text
선행계약 상승
  → 후행계약도 상승하는 경향
```

\[
s=-1
\]

```text
선행계약 상승
  → 후행계약은 하락하는 경향
```

논문도 이 값은 설명적인 상관부호일 뿐 구조적 인과성을 의미하지 않는다고 명시한다.

\[
s
=
\operatorname{sgn}(\operatorname{corr}(L,F))
\]

그러나 부록의 LLM 프롬프트도 예상 부호를 출력한다.

```text
D. LLM 부호는 설명용으로만 사용했는가?
```

이 선택은 매수·매도 방향을 바꾸므로 재현성에 매우 중요하다.

# 거래 프로토콜

## 1. 선행계약 변화율

\[
r_{L,t}
=
\frac{
p_{L,t}-p_{L,t-1}
}{
p_{L,t-1}
}
\]

신호조건은 다음과 같다.

\[
|r_{L,t}|>\theta
\]

기본 실험은 다음 값을 사용한다.

\[
\theta=0
\]

즉, 전일과 가격이 다르면 신호가 발생한다.

## 2. 후행계약 진입

신호가 시점 \(t\)에 발생하면 다음 날인 \(t+1\)에 진입한다.

\[
d_t
=
\operatorname{sign}(r_{L,t})
\times
s(L\rightarrow F)
\]

- \(d_t=+1\): 후행계약의 발생확률 상승에 베팅
- \(d_t=-1\): 후행계약의 발생확률 하락에 베팅

## 예시 1: 같은 방향

```text
선행계약 변화:
+8%

동행부호:
+1

거래방향:
(+1) × (+1) = +1

행동:
후행계약 YES 매수
```

## 예시 2: 반대 방향

```text
선행계약 변화:
+8%

동행부호:
-1

거래방향:
(+1) × (-1) = -1

행동:
후행계약 확률 하락에 베팅
```

## 3. 고정 보유 후 청산

시점 \(t+1\)에 진입한 포지션은 \(h\)일간 보유하고 다음 시점에 청산한다.

\[
t_{\text{exit}}
=
t+h+1
\]

실험한 보유기간은 다음과 같다.

\[
h\in\{1,3,5,7,10,14,21\}
\]

기본값은 다음과 같다.

\[
h=7
\]

## 포지션 크기

논문은 각 거래의 포지션 크기를 `100 per contract`로 설명한다.

하지만 이것이 다음 중 무엇을 의미하는지는 명확하지 않다.

- 계약당 100개 share
- 계약당 $100 notional
- 가격 1포인트당 $100
- 하나의 이벤트쌍에서 동시에 발생한 거래의 집계규모

# PnL 계산

일반적인 YES share를 \(q\)개 매수했다면 가격을 달러단위로 환산한 PnL은 다음과 같다.

\[
PnL^{long}
=
q
\left(
P_{\text{exit}}-P_{\text{entry}}
\right)
\]

하락 방향 포지션은 다음처럼 표현할 수 있다.

\[
PnL^{short}
=
q
\left(
P_{\text{entry}}-P_{\text{exit}}
\right)
\]

이를 통합하면 다음과 같다.

\[
PnL
=
q\cdot d_t
\left(
P_{F,t+h+1}-P_{F,t+1}
\right)
\]

단, \(P\)가 센트 단위라면 달러로 변환해야 한다.

\[
P^{USD}
=
\frac{p^{cent}}{100}
\]

## 보고된 PnL 단위의 확인 필요성

일반적인 이진 예측시장 share는 한 계약당 최대 지급액이 $1이다.

만약 실제로 100 shares만 보유했다면 단일 거래의 최대 절대수익은 대략 $100을 넘기 어렵다. 그러나 논문의 평균 이익은 $724로 보고된다.

따라서 다음 가능성을 확인해야 한다.

- 가격 포인트에 계약수를 곱한 값을 달러처럼 표시했는가?
- 여러 계약 또는 신호를 하나의 trade로 집계했는가?
- `100 per contract`가 100 shares를 의미하지 않는가?
- 계약 multiplier가 별도로 존재하는가?
- 표의 Avg Win이 개별 주문이 아니라 윈도·쌍 단위 집계인가?

원문은 정확한 PnL 단위변환과 거래 단위를 충분히 정의하지 않는다. 실거래 경제성을 평가하려면 반드시 확인해야 한다.

거래당 기대손익은 다음과 같이 표현할 수 있다.

=

+
(1-p_w)\mu_l

- \(\mu_w\): 평균 이익
- \(\mu_l\): 평균 손실, 음수

통계 접근의 단순 기대값은 다음과 같다.

\[

+
0.486(-649)
\approx56.72
\]

\[

+

| --- | --- | ---: | ---: | ---: |
| 중국 2022 GDP 성장률 >5% | 세계 2022 GDP 성장률 >3% | 23 | 17 | +$1,100 |
| 일본 2026 경기침체 | 미국 2025년 1분기 GDP 성장률 >2% | 71 | 5 | +$700 |
| 미국 2025 원유생산 >14.5M bbl/day | 브라질 2025 인플레이션 >5.5% | 24 | 15 | +$600 |
| 인도 2026 경기침체 | 2024년 4분기 CRE 연체율 >3% | 51 | 3 | +$200 |

논문은 일본 경기침체 → 미국 GDP 사례에서 다음과 같은 간접 경로를 제시한다.

```text
일본 경기침체
  → 국내 수요 약화
  → 무역·금융시장·정책 파급
  → 주요국 성장률 압력
```

## 사례 해석의 주의점

이 예시들은 선택된 성공사례다.

다음 정보가 없으므로 전체 rescue 효과를 정량적으로 판단하기 어렵다.

- 순위가 상승한 전체 관계 수
- 순위 상승 관계의 평균 PnL
- 순위 상승 후 손실을 낸 관계
- 순위가 하락했지만 실제 수익을 낸 관계
- semantic score와 미래 PnL의 상관
- 사례 선정 기준

# LLM 학습시점 이후 평가

LLM이 과거 사건 결과를 사전학습 중 이미 알고 있어 의미평가에 미래정보가 섞였을 가능성이 있다.

논문은 이를 줄이기 위해 2024-05-31 이후 진입거래만 별도로 평가한다.

| 지표 | Statistical | Hybrid | 변화 |
| --- | ---: | ---: | ---: |
| 승률 | 61.8% | 62.1% | +0.3%p |
| 평균 이익 | $614 | $656 | +6.8% |
| 평균 손실 | -$700 | -$418 | 손실 절댓값 40.3% 감소 |
| 총 PnL | $3,800 | $7,200 | +89% |

## 해석

승률 개선은 0.3%p로 거의 없지만 평균 손실 감소는 유지된다.

\[
\frac{700-418}{700}
\times100
\approx40.29\%
\]

이는 `LLM이 미래 결과를 이미 알고 있었기 때문에 성과가 좋아졌다`는 설명만으로 전체 결과를 설명하기 어렵게 한다.

다만 학습 cutoff 이후라는 것만으로 다음 문제가 모두 제거되는 것은 아니다.

- 모델이 웹 또는 도구를 사용했는지
- 사건 설명에 결과를 암시하는 문구가 포함됐는지
- 계약 생성일과 평가일의 관계
- 사후 수정된 계약설명을 사용했는지
- GPT-5-nano의 정확한 학습 cutoff와 모델 snapshot

# 다른 LLM 모델

부록은 GPT-5-mini로 전체 의미 재정렬을 다시 수행했고 평균 손실 감소 경향이 유지됐다고 설명한다.

하지만 GPT-5-mini의 상세 표는 제공하지 않는다.

따라서 다음은 확인할 수 없다.

- 정확한 승률
- 평균 손실
- 총 PnL
- GPT-5-nano와의 순위 일치율
- 모델별 부호 일치율
- 모델 비용과 지연시간
- 오픈소스 모델에서도 같은 효과가 나타나는지

# 장점

## 1. LLM의 역할을 명확하게 제한

LLM에게 수치예측 전체를 맡기지 않는다.

```text
통계모델:
방향성 후보 탐색

LLM:
경제적 말이 되는지 검토
```

각 모델이 강한 부분을 분리한다.

## 2. 자연어 명제와 시계열이 직접 연결된 시장을 사용

일반 자산보다 의미검증이 용이하다.

## 3. 미래 테스트구간으로 관계 품질을 평가

인샘플 설명력이 아니라 아웃오브샘플 PnL을 사용한다.

## 4. 수익보다 손실 통제 메커니즘을 분리해 분석

평균 이익 감소와 평균 손실 감소를 함께 제시해 LLM의 역할을 과장된 예측력보다 리스크 관리로 해석한다.

## 5. 보유기간과 큰 가격변화 구간에서 강건성 확인

특정 7일 설정 하나에만 결과가 의존하지 않는다는 근거를 제공한다.

# 중요한 한계

## 1. Granger causality는 구조적 인과가 아님

Granger 검정은 예측정보를 검사한다.

다음 상황에서도 유의할 수 있다.

```text
숨은 공통원인 Z
  ├─ Leader
  └─ Follower
```

Leader가 Follower를 직접 발생시키지 않아도 시간적으로 먼저 반응하면 Granger 관계가 나타날 수 있다.

## 2. 공식적인 다중검정 보정이 없음

대규모 쌍·양방향·다중 lag 탐색은 데이터 스누핑 위험이 크다.

LLM 필터가 실용적인 2차 방어막일 수 있지만 FDR을 대체하는 수학적 보정이라고 단정하면 안 된다.

## 3. LLM 재정렬 공식이 충분히 제시되지 않음

구조화 출력에서 최종 순위로 가는 계산규칙이 없다.

## 4. LLM 부호와 Pearson 부호의 관계가 불명확

실제 거래 방향을 어느 부호가 결정했는지 명확히 해야 한다.

## 5. 사건설명 입력 범위가 일관되지 않음

본문은 title과 description을 제공한다고 설명하지만 부록 프롬프트 그림은 title placeholder만 보여준다.

- 제목만 사용
- 전체 설명 사용
- 규칙·해결조건 포함

중 무엇인지에 따라 결과가 달라질 수 있다.

## 6. PnL 계산단위가 불명확

100단위 포지션과 평균 $724 수익의 관계를 재현하기 어렵다.

## 7. 거래비용이 없음

다음이 반영됐는지 설명되지 않는다.

- bid-ask spread
- 수수료
- 주문장 깊이
- 부분체결
- 시장충격
- 가격이 급변한 뒤 다음 날 진입할 수 있는 실제 유동성
- 하락 포지션의 구현방식
- 계약 만기 직전 거래 제한

## 8. 자본 제약이 없음

여러 사건쌍에서 동시에 신호가 발생할 수 있다.

필요한 정보:

- 총 초기자본
- 동시 포지션 수
- 쌍별 배분
- 동일 계약 중복 노출
- 같은 선행사건의 중복 신호
- 자본 부족 시 우선순위
- 손익 재투자 여부

## 9. PnL 이외의 포트폴리오 지표 부족

다음이 없다.

- MDD
- Sharpe Ratio
- Sortino Ratio
- 변동성
- turnover
- exposure
- VaR·CVaR
- 월별·윈도별 손익
- 최악 테스트 윈도

평균 손실 감소가 포트폴리오 최대낙폭 감소로 직접 이어졌다고 단정할 수 없다.

## 10. 통계적 유의성 평가 부족

- bootstrap confidence interval
- 거래 간 독립성
- paired test
- block bootstrap
- reality check
- SPA test
- multiple strategy correction

총 PnL 차이가 우연인지 검정하지 않는다.

## 11. 짧은 학습 윈도

60일 표본에서 lag 5 VAR를 추정하면 표본이 작다. 결측치와 차분까지 적용하면 유효 표본이 더 줄어든다.

## 12. 선택된 정성 사례의 생존자 편향

성공한 재정렬 사례만 보면 LLM의 rescue 효과가 실제보다 크게 보일 수 있다.

## 13. 재현 코드·데이터 명세 부족

원문만으로는 다음을 완전히 재현하기 어렵다.

- 데이터 다운로드 방식
- 시장 필터
- 가격 종류
- 결측치 처리
- 계약 중복 제거
- 정확한 re-ranking
- PnL 단위
- 거래 충돌 처리

# 개선된 후보 점수 예시

논문은 구체적인 하이브리드 점수식을 제시하지 않는다.

실무에서는 다음처럼 구성할 수 있다.

\[
Score_{i\rightarrow j}
=
w_1S_{\text{granger}}
+
w_2S_{\text{stability}}
+
w_3S_{\text{semantic}}
+
w_4S_{\text{liquidity}}
-
w_5S_{\text{cost}}
\]

- \(S_{\text{granger}}\): FDR 보정된 통계적 강도
- \(S_{\text{stability}}\): 여러 학습윈도에서 관계가 유지된 비율
- \(S_{\text{semantic}}\): LLM 의미 점수
- \(S_{\text{liquidity}}\): 후행계약의 거래 가능성
- \(S_{\text{cost}}\): spread·fee·impact

예를 들어 다음처럼 정규화할 수 있다.

\[
S_{\text{granger}}
=
-\log_{10}
\left(
\max(q\text{-value},10^{-12})
\right)
\]

여기서 q-value는 다중검정이 보정된 p-value다.

# 한국 주식시장에 적용하는 방법

예측시장과 달리 주식에는 한 가격에 여러 정보가 섞인다. 따라서 종목명만 LLM에 주면 의미 필터가 부정확할 수 있다.

## 통계 단계

```text
KOSPI·KOSDAQ 종목수익률
  ↓
정상성 확인
  ↓
업종·시가총액·유동성 필터
  ↓
rolling Granger
  ↓
FDR
  ↓
선행→후행 후보
```

주가 수준보다 수익률 또는 차분 로그가격을 사용한다.

\[
r_{i,t}
=
\log P_{i,t}
-
\log P_{i,t-1}
\]

## 의미 단계

LLM에 다음 근거를 제공한다.

- 기업 사업부문
- 공급망 관계
- 고객·납품 관계
- 원자재 노출
- 환율 민감도
- 금리 민감도
- 지분관계
- 동일 테마 여부
- 공시와 산업분류
- 관계의 최신성

```text
Leader:
정유기업

Follower:
항공기업

전달경로:
유가 상승
  → 항공유 비용 상승
  → 항공사 마진 악화
```

# 하이퍼그래프 논문과의 연결

하이퍼그래프 기반 시스템은 여러 자산과 사건의 N:N 관계를 명시적인 구조로 표현한다.

이 논문은 사건쌍 단위다.

```text
Leader → Follower
```

두 접근을 결합하면 다음과 같다.

```text
pairwise Granger
  ↓
의미필터
  ↓
검증된 방향엣지
  ↓
금융 하이퍼그래프에 등록
  ↓
여러 엣지를 연결해
복합 전달경로 분석
```

예:

```text
금리 인상
  → 달러 강세
  → 원자재 가격
  → 신흥국 인플레이션
  → 소비·GDP
```

LLM 의미 필터를 하이퍼엣지 생성 전의 검증기로 사용할 수 있다.

# 핵심 결론

이 논문의 가장 중요한 메시지는 다음과 같다.

```text
통계모델이 후보를 넓게 찾고,
LLM은 말이 되지 않는 관계를 제거한다.
```

LLM은 직접 가격을 예측하지 않는다. Granger 검정이 만든 Top 100 후보를 경제적 메커니즘에 따라 재정렬하고 최종 Top 20을 선정한다.

기본 실험에서 하이브리드 접근은 다음 결과를 보였다.

- 승률: 51.4% → 54.5%
- 평균 이익: $724 → $636
- 평균 손실: -$649 → -$347
- 총 PnL: $4,100 → $12,500

따라서 성과개선은 더 큰 평균 이익이 아니라 더 작은 평균 손실에서 나왔다.

그러나 다음 사실도 함께 기억해야 한다.

- Granger causality는 구조적 인과를 증명하지 않는다.
- 공식적인 다중검정 보정이 제시되지 않는다.
- LLM 재정렬 점수식과 부호 결합규칙이 불명확하다.
- PnL 단위와 100단위 포지션의 관계가 불명확하다.
- 수수료·스프레드·유동성·자본제약이 충분히 설명되지 않는다.
- Sharpe와 MDD는 보고되지 않았다.
- 신뢰구간과 통계적 유의성 검정이 없다.

따라서 이 연구는 완성된 자동매매전략이라기보다, **통계적으로 발견한 금융 관계 위에 LLM을 의미론적 리스크 관리 계층으로 배치하는 설계 패턴**으로 보는 것이 가장 정확하다.
