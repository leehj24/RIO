## 한눈에 보기

이 논문은 LLM 멀티 에이전트의 높은 추론 능력과 강화학습·경량 신경망의 빠른 실행 속도를 하나의 시스템으로 결합한다.

핵심 구조는 인간의 이중 프로세스 이론을 모방한 두 단계다.

```text
System 2: 느리지만 깊게 생각하는 Teacher
  ├─ 뉴스·가격·거시지표 통합
  ├─ 동적 금융 하이퍼그래프 구축
  ├─ 전이 엔트로피로 인과관계 후보 검증
  ├─ 분석가·리스크 관리자·트레이더 토론
  └─ 정책·리스크·추론 경로 생성
                  ↓ 지식·추론 증류
System 1: 빠르게 실행하는 Student
  ├─ 틱·오더북·기술지표 입력
  ├─ 1D-CNN/TCN + 경량 정책 네트워크
  ├─ System 2 컨텍스트 벡터 비동기 주입
  └─ Long·Short·Close·Hold 및 주문가격 출력
```

System 2는 30분 주기나 뉴스·급등락·최대낙폭 돌파 같은 이벤트가 발생했을 때만 실행된다. System 1은 매 틱마다 기존에 증류된 정책으로 주문을 실행한다.

논문은 제안 모델이 2022-2023년 테스트에서 다음 성과를 냈다고 보고한다.

## 해결하려는 문제

논문은 금융 AI가 다음 두 목표를 동시에 충족하기 어렵다고 본다.

### 복잡성

금리, 환율, 주식, 채권, 옵션, 뉴스, 기업실적은 1:1 관계가 아니라 다수의 변수가 동시에 얽힌 N:N 관계를 형성한다.

예를 들어 다음 사건은 하나의 단순한 엣지로 충분히 표현하기 어렵다.

```text
금리 인상
  ├─ 성장주 할인율 상승
  ├─ 채권가격 하락
  ├─ 달러 강세
  ├─ 원자재 수요 변화
  └─ 기술기업 자금조달 비용 상승
```

일반 지식 그래프는 주로 두 노드의 관계를 나타내지만, 하이퍼그래프는 하나의 하이퍼엣지가 여러 노드를 동시에 연결할 수 있다.

### 즉시성

LLM 멀티 에이전트는 뉴스와 시장 맥락을 해석할 수 있지만, 반복적인 LLM 호출과 토론 때문에 수 초가 걸릴 수 있다.

반대로 강화학습이나 경량 신경망은 밀리초 단위로 실행할 수 있지만 뉴스·공시·거시경제 충격의 의미를 직접 이해하기 어렵다.

논문은 이를 다음처럼 분리한다.

| 구분 | System 2 Teacher | System 1 Student |
| --- | --- | --- |
| 사고 방식 | 숙고적·논리적 | 직관적·고속 |
| 주요 모델 | GPT-4/GPT-4o, 하이퍼그래프, 멀티 에이전트 | 1D-CNN/TCN, Tiny Transformer·SLM·LSTM |
| 입력 | 뉴스, 공시, 가격, 거시지표, 구조적 관계 | 틱, 오더북, VWAP, RSI, MACD, 컨텍스트 벡터 |
| 실행 주기 | 30분 또는 이벤트 발생 시 | 매 틱 |
| 주요 역할 | 시장 구조와 위험 추론 | 즉시 주문 실행 |
| 속도 | 느림 | 논문 주장 기준 평균 12ms |
| 출력 | 정책·리스크·추론 경로 | Long·Short·Close·Hold와 주문가격 |

# System 2: 동적 금융 하이퍼그래프

## 하이퍼그래프 정의

시점 \(t\)의 금융 하이퍼그래프는 다음과 같이 정의된다.

\[
\mathcal{H}_t=(V_t,E_t)
\]

- \(V_t\): 노드 집합
- \(E_t\): 하이퍼엣지 집합

노드는 다음 세 범주를 포함한다.

```text
Asset
  ├─ 개별 주식
  ├─ ETF
  ├─ 채권
  └─ 옵션 등 파생상품

Macro
  ├─ 기준금리
  ├─ 국채금리
  ├─ 환율
  ├─ CPI
  └─ VIX

Event
  ├─ 기업 실적
  ├─ 파산
  ├─ 금리 결정
  ├─ 규제 발표
  └─ 뉴스에서 추출한 정형 이벤트
```

일반 그래프의 엣지는 보통 다음과 같다.

```text
금리 → 기술주
```

하이퍼엣지는 여러 원인·매개·결과를 한 관계 안에 넣을 수 있다.

```text
Hyperedge E42
Drivers:
  - 연준 금리 인상
  - 물가 예상 상회

Mediators:
  - 할인율 상승
  - 자금조달 비용 상승
  - 달러 강세

Targets:
  - 기술주
  - 장기채
  - 신흥국 통화
```

## 하이퍼그래프의 incidence matrix

논문은 incidence matrix의 구체적 수식을 제시하지 않지만, 구현에서는 보통 다음 행렬로 노드와 하이퍼엣지의 소속 관계를 표현한다.

\[
\mathbf{H}_{v,e}=
\begin{cases}
1, & v\in e\\
0, & v\notin e
\end{cases}
\]

여기서 행은 노드, 열은 하이퍼엣지다.

예를 들어 다음과 같은 관계가 있다고 하자.

```text
E1: 금리, 기술주, 장기채
E2: 유가, 항공주, 정유주
E3: SVB, 스타트업, 기술주, 국채
```

incidence matrix는 다음과 같이 만들 수 있다.

| 노드 | E1 | E2 | E3 |
| --- | ---: | ---: | ---: |
| 금리 | 1 | 0 | 0 |
| 기술주 | 1 | 0 | 1 |
| 장기채 | 1 | 0 | 0 |
| 유가 | 0 | 1 | 0 |
| 항공주 | 0 | 1 | 0 |
| 정유주 | 0 | 1 | 0 |
| SVB | 0 | 0 | 1 |
| 스타트업 | 0 | 0 | 1 |
| 국채 | 0 | 0 | 1 |

이 구조를 사용하면 같은 하이퍼엣지에 속한 여러 자산과 이벤트 사이에서 정보를 함께 전파할 수 있다.

## HGNN 정보 전파

논문은 HGNN과 HyperGCN 방식을 차용한다고 설명하지만, 실제 레이어의 정확한 전파식은 제시하지 않는다.

일반적인 HGNN 레이어는 다음 형태로 구현할 수 있다.

\[
X^{(l+1)}
=
\sigma
\left(
D_v^{-1/2}
H
W
D_e^{-1}
H^\top
D_v^{-1/2}
X^{(l)}
\Theta^{(l)}
\right)
\]

- \(X^{(l)}\): \(l\)번째 레이어의 노드 특징
- \(H\): incidence matrix
- \(W\): 하이퍼엣지 가중치 행렬
- \(D_v\): 노드 차수 행렬
- \(D_e\): 하이퍼엣지 차수 행렬
- \(\Theta^{(l)}\): 학습 파라미터
- \(\sigma\): 활성화 함수

이 식은 **논문이 직접 제시한 식이 아니라**, 논문이 인용한 HGNN을 실제로 구현할 때 사용할 수 있는 대표적인 형태다. 재현 시에는 HGNN, HGNN+, HyperGCN 중 어떤 전파식을 사용했는지 확정해야 한다.

# 하이퍼엣지 생성

## 1단계: LLM 인과관계 가설 생성

뉴스와 공시를 FinBERT로 임베딩한 뒤 LLM이 잠재적인 관계를 생성한다.

```text
입력:
  "미 연준이 예상보다 높은 폭으로 금리를 인상했다."

LLM 가설:
  금리 인상
    → 할인율 상승
    → 장기 성장주의 현재가치 하락
    → 기술주 약세

추가 가설:
  금리 인상
    → 달러 강세
    → 원자재·신흥국 자산 압박
```

이 단계의 출력은 아직 확정된 인과관계가 아니라 검증 대상 가설이다.

## 2단계: 전이 엔트로피 검증

논문은 다음 조건을 통과한 관계만 하이퍼엣지로 활성화한다.

\[
TE_{X\rightarrow Y}>\theta
\]

- \(TE_{X\rightarrow Y}\): 변수 \(X\)의 과거가 \(Y\)의 미래를 추가로 설명하는 정보량
- \(\theta\): 관계 활성화 임계값

전이 엔트로피의 일반적인 정의는 다음과 같다.

\[
TE_{X\rightarrow Y}
=
\sum
p(y_{t+1},y_t^{(k)},x_t^{(l)})
\log
\frac{
p(y_{t+1}\mid y_t^{(k)},x_t^{(l)})
}{
p(y_{t+1}\mid y_t^{(k)})
}
\]

의미는 다음과 같다.

```text
Y 자신의 과거만 알고 있을 때의 예측
                vs
Y의 과거와 X의 과거를 함께 알 때의 예측
```

\(X\) 정보를 추가했을 때 \(Y\)의 미래 불확실성이 줄어들면 \(TE_{X\rightarrow Y}\)가 양수가 된다.

### 예시

```text
X: VIX 변화
Y: 기술주 수익률
```

VIX의 과거값을 추가했을 때 기술주 미래수익률의 조건부 분포를 더 잘 설명한다면 다음 관계의 근거가 된다.

```text
VIX 상승 → 기술주 하락 위험 증가
```

## 전이 엔트로피 해석 시 주의점

전이 엔트로피는 방향성이 있는 정보흐름을 측정하지만, 그 자체만으로 경제학적 인과관계를 완전히 증명하지는 않는다.

다음 문제가 남는다.

- 공통 원인에 의한 허위 관계
- 시계열 비정상성
- 표본 크기 부족
- 지연시차 선택에 따른 결과 변화
- 시장 국면 변화
- 여러 관계를 동시에 검사할 때의 다중검정 문제
- 연속형 변수의 확률밀도 추정 오차

재현 시 최소한 다음 값이 필요하다.

```yaml
transfer_entropy:
  window_size: ?
  lag_x: ?
  lag_y: ?
  estimator: histogram | kernel | kNN
  bins_or_neighbors: ?
  threshold_theta: ?
  significance_test: permutation
  permutations: ?
  p_value: ?
  multiple_testing_correction: ?
```

논문은 \(TE>\theta\) 조건을 제시하지만, \(\theta\), 윈도 크기, 시차, 추정법, 유의성 검정 방식은 구체적으로 밝히지 않는다.

# 시장 국면에 따른 동적 가중치

하이퍼엣지의 가중치는 다음과 같이 계산된다.

\[
w_e(t)
=
\alpha S_{\text{str}}
+
\beta R_{\text{att}}(S_t)
\]

- \(S_{\text{str}}\): 전이 엔트로피 등으로 계산한 구조적 관계 강도
- \(S_t\): 시점 \(t\)의 시장 국면
- \(R_{\text{att}}(S_t)\): 현재 국면에서 해당 관계에 부여할 주의 집중값
- \(\alpha,\beta\): 두 요소의 비중

### 예시

평상시에는 다음과 같다고 가정한다.

\[
S_{\text{str}}=0.7,\quad
R_{\text{att}}(S_t)=0.2,\quad
\alpha=0.6,\quad
\beta=0.4
\]

\[
w_e(t)
=
0.6(0.7)+0.4(0.2)
=
0.50
\]

고변동성 국면에서 VIX 관련 리스크 엣지의 attention이 0.9로 증가하면 다음과 같다.

\[
w_e(t)
=
0.6(0.7)+0.4(0.9)
=
0.78
\]

동일한 구조적 관계라도 시장 국면이 변하면 가중치가 0.50에서 0.78로 증가한다. 이 계산은 논문식을 이해하기 위한 예시이며, 논문이 실제로 사용한 \(\alpha,\beta\) 값은 제시되지 않는다.

## 오더북 불균형

논문은 오더북 불균형을 입력으로 사용하지만 계산식을 제시하지 않는다. 일반적으로 다음과 같이 계산할 수 있다.

\[
OBI_t
=
\frac{
Q^{bid}_t-Q^{ask}_t
}{
Q^{bid}_t+Q^{ask}_t
}
\]

- \(Q^{bid}_t\): 매수호가 잔량
- \(Q^{ask}_t\): 매도호가 잔량

해석은 다음과 같다.

- \(OBI_t\approx 1\): 매수잔량 우세
- \(OBI_t\approx -1\): 매도잔량 우세
- \(OBI_t\approx 0\): 균형

예를 들어 매수잔량이 12,000주, 매도잔량이 8,000주면 다음과 같다.

\[
OBI
=
\frac{12000-8000}{12000+8000}
=
0.2
\]

## VWAP

\[
VWAP_t
=
\frac{
\sum_{i=1}^{n} P_iV_i
}{
\sum_{i=1}^{n}V_i
}
\]

현재가격이 VWAP보다 높으면 해당 구간의 평균 체결가격보다 위에서 거래되고 있음을 뜻한다.

# 추론 증류

## 일반 지식 증류와의 차이

일반적인 지식 증류는 교사의 최종 출력분포만 학생이 모방한다.

```text
Teacher logits → Student logits
```

이 논문은 최종 정책뿐 아니라 하이퍼그래프 추론 경로의 표현도 학생에게 전달한다.

```text
Teacher 정책분포
Teacher 하이퍼그래프 임베딩
Teacher 추론 경로
              ↓
Student 정책분포와 잠재공간 정렬
```

## 정책 증류 손실

교사와 학생의 정책분포를 각각 \(P_T\), \(P_S\)라고 하면 다음 KL 발산을 사용한다.

\[
L_{\text{policy}}
=
D_{KL}(P_T\parallel P_S)
\]

온도 \(T\)를 적용한 확률분포는 일반적으로 다음과 같다.

\[
P_T^{(T)}
=
\operatorname{softmax}
\left(
\frac{z_T}{T}
\right)
\]

\[
P_S^{(T)}
=
\operatorname{softmax}
\left(
\frac{z_S}{T}
\right)
\]

온도가 높아지면 최상위 행동 이외의 확률도 부드럽게 드러나 교사가 행동 간 유사도를 전달할 수 있다.

예를 들어 원래 logits가 다음과 같다고 하자.

```text
Long: 4
Short: 1
Close: 0
Hold: 2
```

\(T=1\)에서는 Long이 강하게 지배하지만 \(T=4\)에서는 분포가 평탄해져 Hold와 Short에 대한 교사의 상대적 판단도 학생이 학습하기 쉬워진다.

## 추론 경로 증류 손실

System 2의 그래프 임베딩과 System 1의 잠재벡터를 정렬한다.

\[
L_{\text{reasoning}}
=
\left\|
H_{\text{graph}}
-
H_{\text{student}}
\right\|_2^2
\]

두 벡터가 가까워질수록 학생이 교사의 시장 국면·위험 구조를 내부 표현에 반영했다고 본다.

다만 두 벡터의 차원이 다르면 projection layer가 필요하다.

\[
\hat H_{\text{student}}
=
W_pH_{\text{student}}+b_p
\]

\[
L_{\text{reasoning}}
=
\left\|
H_{\text{graph}}
-
\hat H_{\text{student}}
\right\|_2^2
\]

논문은 projection 구조나 벡터 정규화 방식은 설명하지 않는다.

## 태스크 손실

실제 시장 라벨과 학생의 출력 차이를 줄인다.

분류 문제라면 다음 cross-entropy를 사용할 수 있다.

\[
L_{\text{task}}
=
-\sum_c y_c\log P_{S,c}
\]

가격이나 수익률 회귀라면 다음 MSE를 사용할 수 있다.

\[
L_{\text{task}}
=
\frac{1}{N}
\sum_{i=1}^{N}
(y_i-\hat y_i)^2
\]

논문은 MSE 또는 Cross-Entropy를 사용할 수 있다고 설명하지만 실제 실험에서 어떤 라벨과 손실을 사용했는지 확정하지 않는다.

## 논문 본문의 증류 손실

본문은 다음 식을 제시한다.

\[
L_{\text{total}}
=
\alpha L_{\text{task}}
+
(1-\alpha)T^2L_{\text{distill}}
\]

\[
L_{\text{distill}}
=
D_{KL}(P_T\parallel P_S)
+
\lambda
\left\|
H_{\text{graph}}
-
H_{\text{student}}
\right\|_2^2
\]

부록의 설정은 다음과 같다.

- \(\alpha=0.6\)
- \(T=4.0\)
- Student learning rate: \(3\times10^{-4}\)
- Batch size: 256
- 텍스트 임베딩 차원: 768

식을 그대로 대입하면 다음과 같다.

\[
L_{\text{total}}
=
0.6L_{\text{task}}
+
0.4\times4^2L_{\text{distill}}
\]

\[
L_{\text{total}}
=
0.6L_{\text{task}}
+
6.4L_{\text{distill}}
\]

즉, 손실의 원시 스케일만 보면 증류항 앞의 계수는 6.4가 된다. 다만 KL과 MSE의 실제 수치 범위가 다르므로 계수만으로 증류가 항상 더 강하다고 단정할 수는 없다. 손실 정규화와 \(\lambda\) 값이 필요하다.

## 손실 함수 표기의 내부 불일치

논문의 그림 4에는 다음 형태가 표시된다.

\[
L_{\text{total}}
=
\alpha L_{\text{task}}
+
\beta L_{\text{policy}}
+
\gamma L_{\text{reasoning}}
\]

반면 본문에는 다음 형태가 적혀 있다.

\[
L_{\text{total}}
=
\alpha L_{\text{task}}
+
(1-\alpha)T^2
\left(
L_{\text{policy}}
+
\lambda L_{\text{reasoning}}
\right)
\]

두 식은 가중치 구조가 다르다.

재현 시 다음 중 어느 식이 실제 코드에 사용되었는지 확인해야 한다.

```text
A. 독립 3항 방식
L = α L_task + β L_policy + γ L_reasoning

B. 통합 증류 방식
L = α L_task + (1-α)T²(L_policy + λL_reasoning)
```

이 차이는 학습 결과에 직접 영향을 주는 중요한 재현성 문제다.

# t-SNE 시각화 해석

논문의 그림 5는 증류 전에는 학생 표현이 Bull·Bear·Volatility 국면 사이에 흩어져 있고, 증류 후에는 교사 표현과 겹치는 모습을 제시한다.

이는 학생 잠재공간이 교사와 정렬되었다는 시각적 예시다.

다만 t-SNE는 다음 한계를 가진다.

- 겹쳐 보인다는 사실만으로 실제 정책 성능을 증명할 수 없음

보다 강한 검증에는 다음 지표가 필요하다.

```text
- Centered Kernel Alignment(CKA)
- cosine similarity
- Maximum Mean Discrepancy(MMD)
- linear probe accuracy
- regime classification accuracy
- teacher-student action agreement
```

## Fast Path

## 이중 버퍼링

정책 갱신 중에도 주문을 중단하지 않기 위해 두 버전의 가중치를 운용한다.

```text
System 1-A: 현재 실거래에 사용 중
System 1-B: 백그라운드에서 새 Teacher 지식을 학습

B 학습 완료
  → 검증
  → 원자적 가중치 교체
  → B가 Active
  → 기존 A는 다음 학습용 Standby
```

의사코드는 다음과 같다.

```python
active_model = model_a
standby_model = model_b

while market_is_open:
    tick = receive_tick()
    action = active_model.predict(tick, active_context)
    execute(action)

    if teacher_triggered():
        new_context, teacher_targets = run_system2()
        train(standby_model, teacher_targets)

        if validate(standby_model):
            active_model, standby_model = standby_model, active_model
            active_context = new_context
```

실제 운용에서는 교체 전 다음 검증이 추가되어야 한다.

- 최근 구간 shadow test
- 최대 주문량 제한
- 행동분포 급변 검사
- 기존 모델 대비 손실·회전율 비교
- 롤백 가능 여부
- 모델·컨텍스트 버전 원장 기록

# 평가 지표 계산법

## 누적수익률

\[
CR
=
\frac{V_T-V_0}{V_0}
\]

- \(V_0\): 초기 포트폴리오 가치
- \(V_T\): 테스트 종료 가치

제안 모델의 누적수익률 42.5%는 다음 의미다.

```text
초기 자산 100
→ 테스트 종료 자산 142.5
```

테스트가 정확히 2년이고 중간 현금흐름이 없다고 가정하면 단순 계산한 연복리수익률은 다음과 같다.

\[
CAGR
=
(1+0.425)^{1/2}-1
\approx 19.37\%
\]

이는 논문에 직접 보고된 수치가 아니라 2년 테스트기간을 바탕으로 계산한 참고값이다.

## 샤프지수

일반적인 연환산 샤프지수는 다음과 같다.

\[
Sharpe
=
\frac{
E[R_p-R_f]
}{
\sigma(R_p-R_f)
}
\sqrt{A}
\]

- \(R_p\): 포트폴리오 수익률
- \(R_f\): 무위험수익률
- \(A\): 연환산 계수
  - 일별 수익률: 보통 252
  - 시간별·분별·틱별: 데이터 주기에 따라 달라짐

논문은 Sharpe 2.15를 보고하지만 다음은 밝히지 않는다.

- 수익률 계산 주기
- 무위험수익률
- 연환산 계수
- 일중 포지션의 평가 시점
- 거래비용 차감 여부

따라서 다른 논문의 샤프지수와 직접 비교하려면 동일한 계산규칙이 필요하다.

## 최대낙폭

시점 \(t\)의 낙폭은 다음과 같다.

\[
DD_t
=
\frac{
V_t-\max_{s\le t}V_s
}{
\max_{s\le t}V_s
}
\]

최대낙폭은 다음과 같다.

\[
MDD
=
\min_t DD_t
\]

MDD -9.2%는 이전 최고점에서 가장 크게 하락한 구간이 9.2%였다는 뜻이다.

## 승률

\[
WinRate
=
\frac{
\text{수익 거래 수}
}{
\text{전체 종료 거래 수}
}
\]

논문은 61.8%를 보고하지만 다음은 불명확하다.

- 한 거래의 정의
- 부분청산 처리
- 수수료 차감 전후
- 손익 0 거래 처리
- 종목별 합산 방식
- 보유기간이 겹치는 거래 처리

승률만 높다고 수익성이 보장되지는 않는다. 평균 이익과 평균 손실의 비율도 필요하다.

\[
Expectancy
=
P(win)\times AvgWin
-
P(loss)\times AvgLoss
\]

## 10. latency 단위 표현의 혼재

논문의 정량 결과는 12ms를 제시한다.

그러나 다음 표현이 혼재한다.

- 한글 초록: 밀리초(ms)
- 영문 초록: microsecond(μs)
- 그림 7: microsecond latency 문구
- 표 2: 12ms

12ms는 마이크로초가 아니라 밀리초다.

\[
12ms=12{,}000\mu s
\]

따라서 “마이크로초 단위” 또는 “초고빈도 HFT” 주장은 표의 실측치와 구분해야 한다.

## 11. 비용 계산 근거 부족

월간 토큰 비용 $4,500과 $350의 산출 기준이 없다.

필요한 항목:

- 모델별 토큰 단가
- 월간 Teacher 호출 수
- 호출당 입력·출력 토큰
- 에이전트 수
- 토론 라운드 수
- 캐시 적용
- 재시도
- 뉴스량
- 거래일 수

## 12. t-SNE만으로 증류 성공을 증명하기 어려움

시각화 외에 정량적 표현 정렬 지표가 필요하다.

## 13. SVB 사례의 사후서술 가능성

실시간 로그와 주문 원장이 없으므로 사례가 완전한 역사적 재현인지 확인하기 어렵다.

## 14. 샤프·MDD 계산 조건 부족

성과지표는 계산 주기와 비용 처리에 매우 민감하다. 원시 equity curve와 일별 수익률이 공개되어야 한다.

# 자동매매 시스템에 주는 시사점

## 1. LLM을 실시간 주문 루프에서 분리

가장 실용적인 아이디어는 다음이다.

```text
느린 LLM 분석
  → 정책·리스크 컨텍스트 생성
  → 검증된 경량 정책에 주입
  → 경량 모델이 실시간 주문
```

매 틱 LLM을 호출하는 것보다 현실적이다.

## 2. 컨텍스트에는 만료시간이 필요

## 3. Teacher 결과를 바로 정책 가중치로 배포하면 안 됨

```text
  → risk gate
  → 제한된 자본으로 canary
  → 전체 배포
```

## 가격지연 시뮬레이션

System 2 직접 운용의 느린 응답이 실제 손익에 영향을 줬다는 주장을 검증하려면 다음처럼 지연을 명시적으로 반영해야 한다.

\[
P_{\text{fill}}
=
P(t_{\text{decision}}+\Delta t)
+
Slippage(q,depth,volatility)
\]

- \(\Delta t\): 추론·네트워크·주문 지연
- \(q\): 주문수량
- \(depth\): 오더북 깊이
- \(volatility\): 단기 변동성

단순히 3.2초 후 종가로 체결하는 것보다 실제 호가 리플레이가 필요하다.

# 핵심 결론

이 논문의 가장 중요한 아이디어는 LLM 멀티 에이전트를 더 빠르게 만드는 것이 아니라, **LLM이 수행해야 할 느린 구조적 추론과 실시간 주문 실행을 서로 다른 시간축으로 분리한 것**이다.

```text
LLM Teacher:
  시장의 구조·인과관계·위험을 느리게 갱신

경량 Student:
  Teacher의 정책과 추론표현을 학습해 빠르게 실행
```

하이퍼그래프는 여러 자산과 이벤트의 복합 관계를 표현하고, 전이 엔트로피는 LLM이 제안한 관계를 수치적으로 검증하는 장치로 사용된다. Graph-Grounded Debate는 각 주장을 하이퍼엣지 ID와 연결해 일반적인 자연어 토론의 환각을 줄이려 한다.

추론 증류는 Teacher의 최종 행동뿐 아니라 하이퍼그래프 임베딩과 추론 경로를 Student의 잠재공간에 정렬한다. 비동기 실행과 이중 버퍼링은 Student가 주문을 계속 수행하는 동안 Teacher가 전략을 갱신하게 한다.

다만 논문에 보고된 수익률·MDD·속도·비용 수치를 실제 트레이딩 성과로 일반화하려면 다음이 추가로 검증되어야 한다.

- 시점 정합성이 보장된 원시 데이터
- 거래비용과 호가 기반 체결
- 하이퍼그래프 생성 파라미터
- 정확한 Student 구조
- 실제 사용한 손실식
- 반복실험과 신뢰구간
- 비교모델의 동일 조건 재실행
- SVB 사례의 실제 주문 로그
- 모델·프롬프트·그래프·가중치 버전 기록

따라서 이 논문은 완성된 고빈도 매매 시스템의 재현 명세라기보다, **복잡한 LLM 추론을 저빈도로 실행하고 그 지식을 경량 실시간 모델로 전이하는 금융 AI 아키텍처 제안**으로 보는 것이 가장 정확하다.
