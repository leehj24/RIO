# 지연·추측 디코딩 정책

추측 디코딩은 자체 호스팅 목표 모델과 초안 모델을 가진 서빙 환경의 최적화 기법이다. Gemini_Api2 같은 관리형 API에 대해 에이전트가 임의로 적용하거나 우회하지 않는다.

API 환경에서는 먼저 호출 수 제한, JSON 출력, 입력 요약, 캐시, 병렬화 가능성, 타임아웃, 배치 정책을 측정한다. 자체 호스팅 환경에서만 초안 모델, 목표 모델, 초안 길이, 수락률, 비용비, 샘플링 설정, 모델 버전, 실제 지연을 기록하고 부하 시험한다.

가속은 텍스트 생성 지연만 줄일 수 있다. 뉴스 수집, 데이터베이스, 브로커 왕복, 리스크 검사는 대체하지 않으며 분석 결과의 시간 유효성도 보장하지 않는다.
