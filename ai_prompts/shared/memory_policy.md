# 에이전트 기억 정책

기억은 원자적이고 자기완결적인 가설 노트로 저장한다. 원문 데이터, 모델 생성 요약, 사람이 정정한 사실을 구분하고 provenance를 보존한다.

각 노트는 관측·가설·근거·행동 제안·결과·반증·시간·태그·링크 후보를 포함한다. 기존 기억을 자동으로 덮어쓰지 않고 새 버전과 변경 이유를 남긴다. 손실 사례와 실패 원인도 삭제하지 않는다.

검색된 기억은 현재 판단의 가설 후보일 뿐이다. 최신 데이터, 출처 정책, Python 리스크 규칙을 다시 통과하기 전에는 주문 근거가 될 수 없다.
